### FEATURE 1 — Booking Status Tracker 🔥
**Page:** `/track-booking`

After a customer submits a booking, they should be able to check its status using their email address and booking reference number.

**What to build:**
- Add a `status` field to the bookings table: `received | confirmed | scheduled | completed | cancelled`
- Add a `referenceNumber` field (auto-generated, e.g. `EI-2026-0042`)
- Public API endpoint `GET /api/bookings/track?ref=EI-2026-0042&email=customer@email.com` — returns status without requiring login
- `/track-booking` page with a simple form (email + reference number) that displays a visual progress stepper: **Received → Confirmed → Scheduled → Completed**
- Admin panel: add status dropdown on each booking card so the contractor can update it
- When status changes in admin, automatically send the customer a status update email

### FEATURE 3 — Google Reviews Integration 🔥
**Page:** `/reviews`

The reviews page currently shows "No reviews yet" because no one has manually submitted a review. Pull real Google reviews automatically.

**What to build:**
- Use the **Google Places API** (`https://maps.googleapis.com/maps/api/place/details/json?place_id=PLACE_ID&fields=reviews,rating`)
- Store the Google API key in environment variables
- Cache the Google reviews in the database (refresh every 24 hours via a cron job) so the page loads fast and doesn't hit API limits
- Display Google reviews alongside any manually submitted reviews
- Show a Google badge/star rating summary at the top (e.g. "4.9 ★ on Google — 47 reviews")
- Add a "Leave us a Google Review" button linking to the business Google review URL
- Admin panel: `Site Settings` page — add a field to enter the Google Place ID
