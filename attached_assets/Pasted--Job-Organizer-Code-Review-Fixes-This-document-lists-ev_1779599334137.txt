## Still Needs Fixing in Replit

These files were not fully provided, so the changes must be made manually.

### `admin.py` — Critical security bug

**Find this line (or equivalent):**
```python
if current_user.email == 'admin@example.com':
```

**Replace every admin access check with:**
```python
if not current_user.is_admin:
    abort(403)
```

After deploying, open a Python shell in Replit and grant yourself admin:
```python
from app import app, db
from models import User
with app.app_context():
    u = db.session.get(User, <your_user_id>)
    u.is_admin = True
    db.session.commit()
```

---

### `auth.py` and all POST forms — CSRF protection missing

**Install flask-wtf:**
```
pip install flask-wtf
```

**Add to `app.py` inside `create_app()`:**
```python
from flask_wtf.csrf import CSRFProtect
csrf = CSRFProtect(app)
```

**Add to every HTML form (inside the `<form>` tag):**
```html
<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
```

Without this, any POST route (`/job/<id>/delete`, login, signup, etc.) is vulnerable
to cross-site request forgery.

### `nlp_parser.py` — Phone format mismatch

The parser formats phone numbers as `(XXX) XXX-XXXX` (North American) but the
address extractor targets Australian addresses. If your users are Australian,
update `normalize_phone_number` to format as `04XX XXX XXX`:

```python
def normalize_phone_number(phone_str: str) -> str:
    digits = re.sub(r'\D', '', phone_str)
    if len(digits) == 10 and digits.startswith('0'):
        return f"{digits[:4]} {digits[4:7]} {digits[7:]}"
    return phone_str  # return original if unrecognised
```

### `upload` route in `routes.py` — file type validation

The upload route must check the extension **before** saving and passing to OCR.
`ocr_utils.py` now raises `ValueError` on bad types, but the route should also
reject early and return a clean error to the user:

```python
from ocr_utils import ALLOWED_IMAGE_EXTENSIONS

ALLOWED_EXTENSIONS = ALLOWED_IMAGE_EXTENSIONS | {'.pdf'}

def allowed_file(filename):
    return '.' in filename and \
           os.path.splitext(filename)[1].lower() in ALLOWED_EXTENSIONS

# In your upload route:
if not allowed_file(file.filename):
    flash('File type not allowed.', 'danger')
    return redirect(request.url)
```

### `ocr_utils.py` — PDF support (optional but recommended)

If you want PDF uploads to actually work, install `pdfplumber` and replace
`extract_text_from_pdf`:

```
pip install pdfplumber
```

```python
import pdfplumber

def extract_text_from_pdf(pdf_path: str) -> str:
    with pdfplumber.open(pdf_path) as pdf:
        return '\n'.join(
            page.extract_text() or '' for page in pdf.pages
        ).strip()
```
